# ps-nzbjoin
powershell ps1 script for combining nzb files
Windows Native (No Python)

Drag/Drop support. 

1) right click -> chose run with powershell
2) drag/drop all nzb files to be combined (or type in destination and file names manually)
3) enter location and name of your desired merged nzb file
4) choose y/n to remove original nzb files.
